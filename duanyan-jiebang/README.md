# 端砚 · 揭榜 Demo

访问地址：https://fengxingnuyan.github.io/case/duanyan-jiebang/

周榜、月榜和金榜的独立赛事页面，用于产品与流程评审。
`index.html` 是自包含页面，也可下载后直接打开。

- 周榜：按题配置站内问卷、附件、外部表单及结果说明，首次有效完成后领取一次墨点；问卷示例20墨点，评测示例30墨点。
- 月榜：多版本提交、按批次评测的排行榜，展示本人排名、更新时点和前N名奖励范围；活动结束后由主办方确认正式结果。
- 金榜：大型赛事、历届结果与科研资产档案。
- 交互：继续任务、补正、查看排名及领取奖励直达相应位置，保留操作上下文。
- 端砚衔接：提供创建或关联课题、复制任务说明、返回交付及墨点到账后的使用引导。

报名、提交、审核、资源和奖励为交互演示，记录保存在访问者自己的浏览器，不向实际赛事提交材料。定时评测可通过演示控制模拟运行，不连接真实评测Skill或发奖服务；课题引导不代表已经在端砚创建课题。赛事状态与补设的截止时间均有演示标注，正式信息以赛事主办方发布为准。

发布文件：`duanyan-jiebang/index.html`。GitHub Pages 通过 `main` 分支根目录发布；推送新版本后自动更新。
