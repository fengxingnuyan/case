# 端砚 · 揭榜 Demo

访问地址：https://fengxingnuyan.github.io/case/duanyan-jiebang/

周榜、月榜和金榜的独立赛事页面，用于产品与流程评审。
`index.html` 是自包含页面，也可下载后直接打开。

- 周榜：轻量任务，首次有效完成后领取一次墨点；问卷示例20墨点，评测示例30墨点。
- 月榜：多版本提交与评测反馈，活动结束后由主办方确认揭榜结果。
- 金榜：大型赛事、历届结果与科研资产档案。

报名、提交、审核、资源和奖励为交互演示，记录保存在访问者自己的浏览器，不向实际赛事提交材料。赛事状态与补设的截止时间均有演示标注，正式信息以赛事主办方发布为准。

发布文件：`duanyan-jiebang/index.html`。GitHub Pages 通过 `main` 分支根目录发布；推送新版本后自动更新。
