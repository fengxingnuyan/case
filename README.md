# 端砚 · 课程与实践 Demo

当前版本：V6（2026-11-02）。单文件 HTML 交互原型。

- 在线演示：https://fengxingnuyan.github.io/case/
- 离线使用：下载仓库中的 `index.html`，用浏览器打开。
- 演示入口：课程 → 视频课 → 奖励与结业 → 演示证书；科研实践案例 → 课题空间 → 反馈与墨点。
- 右下角“演示控制台”可切换加载、空白、失败、只读等状态。

课程视频为播放器占位；案例使用合成数据。研究名片、课题资产、贡献与墨点记录只保存在当前浏览器，不操作端砚线上账户。

## V6 更新

- 系列学习奖励的 50% 分到课时，50% 在所有课时有效完成且通过轻量结课验证后领取。
- 展示学习进度及已领／可领／待解锁；支持领取中、失败重试、刷新留存与防重复发奖。
- 提前展示结业证书、发证署名和条件，支持领取、查看及下载非正式演示证书。
- 课时学习、系列结课、案例贡献、采纳追加统一进入同一个演示墨点账本。
- 学习奖励不强制提交案例；拿证不要求公开或被采纳。成功与失败实践按同一证据标准核验。

奖励额度、证书署名和编号均为演示，不代表真实发放或认证。

## 后续更新

本仓库是此项目后续 HTML Demo 的默认发布仓库。将最新的自包含 HTML 更新为根目录 `index.html`，推送至 `main`，GitHub Pages 自动更新。

发布源：`main` 分支根目录。无需依赖安装、服务端或构建步骤。
